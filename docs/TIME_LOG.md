# Time Log

Tracks time spent building this site, for billing/reference purposes.

**Methodology:** Computed from git commit timestamps, clustered into work sessions (a gap of
45+ minutes between commits starts a new session). Each session adds a 20-minute buffer for
design discussion, review, and testing time that didn't produce a commit at the exact start/end
of that window. This undercounts pure discussion/planning time that happens without any commits
at all (e.g. long brainstorming conversations before the first commit of a session) — treat these
numbers as a reasonable floor, not a precise timesheet.
